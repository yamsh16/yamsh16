## 🚀 Featured Projects



### 🧪 [Model Hub](https://github.com/yamsh16/Model-Hub)

**Evaluate, analyze and understand your AI/ML models.**

A web application that evaluates AI/ML models through OpenAI-compatible endpoints without requiring users to write evaluation code.

- Connect models through OpenAI-compatible APIs.
- Evaluate model performance using Accuracy, F1, Precision and Recall.
- Visualize confusion matrices and training loss curves.
- Detect training and testing data leakage.
- Generate model readiness scores and improvement recommendations.
- Chat with connected models directly in the browser.

**Tech Stack:** Next.js, Tailwind CSS, FastAPI, PostgreSQL, Scikit-learn, Docker

[![View Repository](https://img.shields.io/badge/VIEW_PROJECT-8A2BE2?style=for-the-badge&logo=github&logoColor=white)](https://github.com/yamsh16/Model-Hub)

### 🎫 [TicketIQ](https://github.com/yamsh16/TicketIQ)

**AI-powered support ticket classification and root cause analysis.**

An intelligent ticket triage system that predicts ticket type, queue and priority, followed by AI-generated root cause analysis and resolution recommendations.

- Automated ticket classification using BERT-based models.
- Predicts ticket type, queue and priority.
- Uses local LLMs through Ollama (Llama 3 / Mistral).
- Generates ticket-specific root cause analysis.
- Provides resolution steps and preventive measures.

**Tech Stack:** Python, BERT, NLP, Machine Learning, Ollama, Streamlit

[![View Repository](https://img.shields.io/badge/VIEW_PROJECT-8A2BE2?style=for-the-badge&logo=github&logoColor=white)](https://github.com/yamsh16/TicketIQ)

### 📚 [Academic Q&A Bot](https://github.com/yamsh16/Academic-Q-A-Bot)

**Turn academic documents into intelligent study material.**

An AI-powered Python web application that extracts content from academic documents and generates categorized question-and-answer pairs.

- Supports PDF, DOCX and TXT documents.
- Generates questions at Easy, Medium and Hard difficulty levels.
- Uses Meta Llama 3.3 70B for question generation.
- Integrates Groq API for fast LLM inference.
- Provides an interactive Streamlit interface.

**Tech Stack:** Python, Streamlit, Groq API, Llama 3.3 70B, NLP

[![View Repository](https://img.shields.io/badge/VIEW_PROJECT-8A2BE2?style=for-the-badge&logo=github&logoColor=white)](https://github.com/yamsh16/Academic-Q-A-Bot)

### 🤖 [CWT Crypto Agent](https://github.com/yamsh16/cwt-crypto-agent)

**Multi-agent AI system for cryptocurrency prediction market analysis.**

A Hermes-powered multi-agent system designed to analyze BTC and ETH five-minute prediction markets.

- Market discovery across Polymarket and Kalshi.
- Market data collection using Apify and CoinGecko.
- AI-assisted directional predictions using Kronos-style features.
- Multi-agent orchestration for market analysis and prediction.
- Kelly Criterion-based position sizing and risk management.
- FastAPI endpoints for accessing prediction workflows.

**Tech Stack:** Python, Multi-Agent AI, LLMs, FastAPI, Apify, OpenRouter, Kelly Criterion

[![View Repository](https://img.shields.io/badge/VIEW_PROJECT-8A2BE2?style=for-the-badge&logo=github&logoColor=white)](https://github.com/yamsh16/cwt-crypto-agent)
